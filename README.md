# blks

Building blocks for AIML

## Installation

Using `uv`:

```bash
uv add blks
```

Or using `pip`:

```bash
pip install blks
```

## Upgrading

To upgrade to the latest version:

Using `uv`:

```bash
uv add --upgrade blks
```

Or using `pip`:

```bash
pip install --upgrade blks
```

## Quick Start

```python
import blks

print(blks.__version__)
```
